# inventory_management_system

Full-stack Inventory Management System — real-time stock levels, suppliers,
purchases and sales, with automatic stock updates, low-stock and expiry alerts,
and reports.

Stack: Next.js (App Router) frontend + API routes, Prisma, MongoDB, shadcn/ui.

The application lives in [`InventoryManagement/`](./InventoryManagement). See
[InventoryManagement/README.md](./InventoryManagement/README.md) for setup,
environment variables, demo accounts and the API overview.
